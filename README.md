# 飞鼠图鉴

这是两个人共同使用的唯一清单，入口为 https://zxwei.site/momonga-checklist/ 。

网页由 GitHub Pages 托管，清单数据保存于阿里云轻量应用服务器的 SQLite 数据库，接口为 https://101.200.179.45 。免费 HTTPS 证书已签发，每天自动检查续期；续期测试已通过。

原图有手绘斜线的 25 只永久锁定为已买；其他条目和新录入的小鼠可自由切换已买、未买，图片斜线跟随状态变化。支持手机四列浏览、搜索、分组、照片录入、备注、收纳盒、备份导入导出。

两台手机的修改在数据库事务内合并。离线修改暂存在本机，连接恢复后同步；连接失败时可点击重试。初始迁移保留 92 只鼠和 25 个已买标记。

每只鼠可独立标记「我想要」，心愿单筛选展示未收纳的心动鼠。新鼠登记也能勾选「加入心愿单」。心愿状态与购买状态独立，双方同步，备份导入导出保留。旧记录默认没有加入心愿单。
