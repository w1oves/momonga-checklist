# 我们的飞鼠图鉴

手机优先的四列收藏图鉴，按参考图顺序录入 92 只，手绘斜线识别为已买，共 25 只。只有原图带手绘斜线的 25 只锁定为已买；其余原图条目和后来录入的新鼠均可自由切换已买、未买。图片斜线随购买状态出现或消失，原图已有的手绘线直接保留。支持购买标记、筛选、搜索、新鼠照片与分组、改名及备注、分享、备份导入导出。

网页部署于 GitHub Pages。共享数据独立保存于 Sites 管理的 Cloudflare R2；共享链接的随机房间标识只放在 URL fragment 和设备本地，不提交到仓库。持有共享链接者可读写该清单。购买修改与录入使用条件写入及冲突重试，避免两台手机覆盖不同条目。每 8 秒拉取一次，离线写入暂存并在恢复联网后重试。

部分名称按图中造型暂命名，可在网页中修改。原图来源标注保留；原图上的手绘线仍在缩略图中，当前状态以卡片按钮为准。

首次访问根地址会建立一份新清单；两个人应使用同一个带 `#r=` 的分享链接。

共享按钮会生成 `?s=8位邀请码` 的短链接；短码映射保存在云端，不写进公开仓库。
